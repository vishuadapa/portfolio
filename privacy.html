Privacy Policy 

Last updated: October 14, 2026

A personal tool operated by Vishu Adapa for use with his own accounts. It is not offered to the public.

What the app accesses

It uses OAuth to read messages, manage labels, and create drafts in Gmail accounts that the owner explicitly authorizes. It cannot send email, move email to trash, or permanently delete email.

How data is handled

All processing happens on the owner's own computer. OAuth tokens are stored locally with owner-only file permissions. No data is sold, shared, or transferred to any third party, except to the AI assistant the owner chooses to use on his own computer to work with his email.

Google API Services User Data Policy

Gmail MCP's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
